# 公开资料库

这里存档编写题库时采集、阅读和总结过的公开资料。目的不是转载全文，而是保留：

- 原站链接，方便回到原文；
- 每份资料覆盖的题目/主题；
- 原文里值得反复看的解释角度和递进追问；
- 哪些结论有版本或场景边界，不能当成定律。

题目正文会引用这里的来源 id；每题“易错点与追问”页也会显示对应链接。

## 使用原则

1. 原文的题目措辞和讲解很好，但本站题目均重新编写，不逐字复制；需要原文语境时点来源链接。
2. 原站的性能数字、版本行为和公司真题说法只作线索，不作为定论；题库里用“通常/取决于版本”限定。
3. 同一主题在不同版本可能换了参数名或默认值，复习时以当前版本文档和源码为准。
4. 面经只代表公开分享者的经历，不代表公司官方题库。
